Embedding

Embed harness diagrams

Add an interactive, toggleable Schematic and Layout viewer to any documentation page while keeping native harness data in a separate JSON file.

Static & offline-safe Native JSON Schematic + Layout
Why an iframe?

The editor owns global styles, keyboard shortcuts, portals, canvas sizing, and state stores. An iframe gives it a stable boundary without leaking any of that machinery into your documentation app.

Live example

This control loads data/2vD1.json at runtime and starts with one Layout pane. Use the native pane menu to switch its type or add another pane; expand the control when the documentation column gets cramped.

Interactive harness source: data/2vD1.json Open
Edits are held in browser memory and reset on refresh. Remote saves, authentication, realtime, analytics, and telemetry are disabled in this static build.

Quick start

  1. Host the native JSON beside the editor.

    With the default security policy, the JSON source must share the editor's origin.

  2. Pass its path in the src query parameter.

    The loader accepts a bare native document or the existing { document: … } envelope.

  3. Size the iframe container.

    The editor fills the available width and height; the parent page controls the viewport.

HTML
<div class="harness-frame">
  <iframe
    src="/harness-design/embed/?src=/harness-design/data/2vD1.json"
    title="Interactive harness viewer"
    loading="lazy"
  ></iframe>
</div>

<style>
  .harness-frame {
    width: 100%;
    height: min(62vh, 620px);
    min-height: 520px;
    overflow: hidden;
    border: 1px solid #dfe5e2;
    border-radius: 12px;
  }

  .harness-frame iframe {
    display: block;
    width: 100%;
    height: 100%;
    border: 0;
  }
</style>

Native JSON source

The URL can return either the complete database-row envelope or only its native document value. No conversion layer is needed.

data/example-harness.json
{
  "document": {
    "version": 0.5,
    "connectors": [],
    "wires": [],
    "bundles": [],
    "frames": []
  }
}

Responsive sizing

React Flow needs a non-zero viewport. Always give the iframe wrapper an explicit height or minimum height. On phones, 520–600 pixels is generally enough for useful inspection; editing is more comfortable above 700 pixels.

Security model

The static editor permits same-origin JSON fetches only. Supabase, authentication, realtime channels, remote persistence, Sentry, analytics, and feedback transports remain disabled. The page can itself be framed by another origin, but the JSON should stay beside the editor unless you deliberately revise CSP and CORS.
